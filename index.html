    Extended Parameter Capture

    Research only — Function 0x05 / 0x06 / 0x07. Full 5-byte addresses, no parameter mapping.

    When bidirectional is active, Kemper may send strings above $3FFF as extended messages. Start capture, change Performance or Slot on the Kemper, then Stop. Addresses are shown as five bytes and a 32-bit value — they are not truncated to a 2-byte ID.

    Ready — connect Kemper MIDI, then Start Extended Parameter Capture.
